# GVE

## Documentation

The GVE conceptual documentation revolves around two main areas: _intra-document_ and _inter-document_ modeling. The former refers to the representation of a single [snapshot](./autograph.md#basic-terminology), an autograph document; the latter to the representation of the differences among the witnesses converging into a meta-epigram, which is an abstraction.
